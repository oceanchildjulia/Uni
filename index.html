🎯 Exam Prep – Learning Sprint Session 7 · 7 Review-Aufgaben, gelöst

💡 So nutzt du es: Erst selbst rechnen (Papier!), dann Lösung aufklappen und Schritt für Schritt vergleichen. Jede Aufgabe zeigt dir, welche Unit/Regel dahintersteckt — so verknüpfst du Prüfung mit Verständnis.

Task 1 · Integrale (a)–(d) [U1 Calculus, U4 Vector Calculus]

(a) ∫₀^∞ x·e^(−x) dx — Partielle Integration (u = x, dv = e^(−x)dx):

= [−x·e^(−x)]₀^∞ + ∫₀^∞ e^(−x) dx
= 0 + [−e^(−x)]₀^∞ = 0 + (0 − (−1)) = 1

(b) ∫₀^π sin(x)·cos²(x) dx — Substitution u = cos(x), du = −sin(x)dx, Grenzen 1 → −1:

= ∫₁^(−1) −u² du = ∫₋₁¹ u² du = [u³/3]₋₁¹ = 1/3 − (−1/3) = 2/3

(c) ∬_T x·y dA, T = Dreieck (0,0), (1,0), (0,1) → 0 ≤ x ≤ 1, 0 ≤ y ≤ 1−x:

∫₀¹ ∫₀^(1−x) x·y dy dx
= ∫₀¹ x · [y²/2]₀^(1−x) dx
= ∫₀¹ (x/2)(1−x)² dx
= (1/2) ∫₀¹ (x − 2x² + x³) dx
= (1/2)(1/2 − 2/3 + 1/4) = (1/2)(1/12) = 1/24

(d) ∫_C F⃗·dr⃗ mit F⃗ = (1, x+y), r⃗(t) = (sin t, t), t ∈ [0, π]. r⃗′(t) = (cos t, 1):

F(r(t))·r'(t) = (1, sin t + t)·(cos t, 1) = cos t + sin t + t
∫₀^π (cos t + sin t + t) dt = [sin t − cos t + t²/2]₀^π
= (0 − (−1) + π²/2) − (0 − 1 + 0) = 2 + π²/2 ≈ 6.93
Task 2 · sin²(x): Taylor + Fourier-Koeffizient c₀ [U1, U2]

(a) Taylor 2. Ordnung um x₀ = 0. f = sin²x, f′ = sin(2x), f″ = 2cos(2x):

f(0) = 0, f'(0) = 0, f''(0) = 2
T₂f(x) = 0 + 0·x + (2/2!)x² = x²

(b) c₀ = Mittelwert über eine Periode (L = 2π). Mit sin²x = ½ − ½cos(2x) ist der Konstantanteil ½:

c₀ = (1/2π) ∫₀^(2π) sin²t dt = 1/2
Task 3 · f(x) = 2e^(−2x), x ≥ 0: Faltung + Fourier-Transform [U2]

(a) Faltung. Für t ≥ 0 (für t < 0 ist es 0):

(f∗f)(t) = ∫₀ᵗ 2e^(−2x) · 2e^(−2(t−x)) dx
= 4e^(−2t) ∫₀ᵗ dx = 4t·e^(−2t)

(b) Fourier-Transform (Kurs-Konvention f̃(ω) = (1/√(2π)) ∫ f(t)e^(−iωt) dt):

f̃(ω) = (1/√(2π)) ∫₀^∞ 2e^(−2t) e^(−iωt) dt
= (2/√(2π)) ∫₀^∞ e^(−(2+iω)t) dt
= (2/√(2π)) · 1/(2+iω) = √(2/π) / (2+iω)
Task 4 · φ = sin(x + y² − z): Gradient, div-grad, curl-grad [U4]

Setze w = x + y² − z (dann ∂w/∂x=1, ∂w/∂y=2y, ∂w/∂z=−1).

(a) ∇φ = cos(w)·(1, 2y, −1)

(b) div grad φ = Δφ (Laplace-Operator):

∂²φ/∂x² = −sin w
∂²φ/∂y² = 2cos w − 4y² sin w
∂²φ/∂z² = −sin w
Δφ = 2cos w − (4y² + 2) sin w

(c) curl(grad φ) = 0⃗ — immer für glatte φ (gemischte partielle Ableitungen kommutieren; konservativ ⟹ wirbelfrei).

Task 5 · u⃗=(3,0,−1), v⃗=(0,2,1): Projektion + Parallelogrammfläche [U3]

(a) proj_v(u) = (u·v / |v|²)·v. u·v = −1, |v|² = 5:

proj_v(u) = (−1/5)(0, 2, 1) = (0, −2/5, −1/5)

(b) Fläche = |u×v|. u×v = (2, −3, 6):

|u×v| = √(4 + 9 + 36) = √49 = 7
Task 6 · A = [[−1,0,0],[0,2,−1],[0,−1,2]]: Unabhängigkeit, Inverse, Eigenwerte, Diagonalisierung [U5]

(a) Spalten linear unabhängig ⟺ det A ≠ 0:

det A = −1 · det[[2,−1],[−1,2]] = −1·(4−1) = −3 ≠ 0  ✓

(b) Inverse (Blockstruktur: 1×1 Block −1 und 2×2 Block B, B⁻¹ = ⅓[[2,1],[1,2]]):

A⁻¹ = [[−1, 0, 0],
        [0, 2/3, 1/3],
        [0, 1/3, 2/3]]

(c) Eigenwerte aus p_A(λ) = det(A−λI) = (−1−λ)((2−λ)²−1):

λ₁ = −1 → (A+I)x = 0  ⟹  x = (1, 0, 0)ᵀ
λ₂ = 1  → (A−I)x = 0  ⟹  x = (0, 1, 1)ᵀ
λ₃ = 3  → (A−3I)x= 0  ⟹  x = (0, 1, −1)ᵀ

(d) Spalten von S = Eigenvektoren, D = Diagonalmatrix der Eigenwerte:

S = [[1, 0, 0],
     [0, 1, 1],
     [0, 1, −1]],  D = diag(−1, 1, 3),  S⁻¹AS = D
Task 7 · Krebs-Detektion: Cross-Entropy [U6]

Wahre Verteilung p = (0, 1, 0) (benign, One-Hot), Modell q = (0.09, 0.73, 0.18).

H(p,q) = −Σᵢ pᵢ·log₂(qᵢ) = −1·log₂(0.73) ≈ 0.454 bits

Interpretation: „Strafe" für die Unsicherheit des Modells — exakt der Cross-Entropy-Loss, mit dem Klassifikatoren/LLMs trainiert werden.
